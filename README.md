# AI-Powered Network Intrusion Detection & Threat Analytics System

An end-to-end system that combines **Data Science + Cybersecurity + AI/ML** to
detect malicious network traffic in real time, explain *why* traffic was
flagged, and surface insights through an interactive dashboard.

## Features

- **Supervised detection** — Random Forest classifier trained on the
  CICIDS2017 dataset to distinguish benign vs. malicious traffic.
- **Unsupervised anomaly detection** — Isolation Forest to catch
  zero-day-style attacks that don't match known patterns.
- **Explainable AI** — SHAP values show exactly which traffic features
  drove each prediction, instead of a black-box output.
- **RAG-powered Threat Intelligence Assistant** — a ChromaDB vector store
  of MITRE ATT&CK-style attack descriptions, queried via Gemini so the
  dashboard can answer "what is this attack and how do I respond?" with
  grounded, non-hallucinated context.
- **Multi-agent automation pipeline** — a Detection Agent (ML models), a
  Threat Intel Agent (RAG lookup), and a Response Agent (severity scoring
  + simulated action) chained together for an end-to-end agentic workflow.
- **Automated incident response** — rule-based severity scoring that
  auto-"blocks" high-confidence attacker IPs and logs every decision to a
  SQLite incident table, acting as an auto-generated SOC ticket log.
- **AI-generated threat reports** — Gemini summarizes dataset statistics
  into a plain-English threat-landscape report.
- **Live dashboard** — Streamlit app with 3 views: live detection metrics,
  a SOC AI chat assistant, and the automation/incident log.
- **Alerting** — Telegram bot integration for high-severity detections.

## Tech Stack

Python · scikit-learn · SHAP · Streamlit · SQLite · ChromaDB ·
Sentence-Transformers · Gemini API (RAG + agents) · pyngrok

## Multi-Agent Pipeline

```
 Network Traffic
       │
       ▼
┌─────────────────┐     attack detected      ┌──────────────────────┐
│ Detection Agent  │ ────────────────────────▶│ Threat Intel Agent    │
│ (RF + Iso Forest)│                           │ (RAG: ChromaDB+Gemini)│
└─────────────────┘                           └──────────┬───────────┘
                                                          │ context + explanation
                                                          ▼
                                                ┌──────────────────────┐
                                                │  Response Agent       │
                                                │  (severity scoring +  │
                                                │   simulated action)   │
                                                └──────────┬───────────┘
                                                          ▼
                                                  SQLite incident log
```

Run the full pipeline on a single record with:
```python
from src.agent_orchestrator import run_pipeline
run_pipeline(features_row, source_ip="192.168.1.10", gemini_api_key="YOUR_KEY")
```

## Setup

1. **Get the dataset**: Download CICIDS2017 from Kaggle
   (`cicdataset/cicids2017`) and place the CSV file(s) in `data/`.

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Train the models**:
   ```bash
   python src/train_model.py
   ```

4. **Run the dashboard**:
   ```bash
   streamlit run dashboard/app.py
   ```

## Dataset

This project uses [CICIDS2017](https://www.unb.ca/cic/datasets/ids-2017.html),
a labeled network intrusion dataset created by the Canadian Institute for
Cybersecurity. It is not included in this repo due to size — download it
separately and place it in `data/`.
